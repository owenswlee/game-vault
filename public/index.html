Getting started

How it works

1 · Download

Pick a game and grab the .zip. No launcher or account needed.

2 · Unzip

Right-click the file, choose Extract All, and open the folder.

3 · Play

Double-click the game's .exe. If Windows SmartScreen appears, click More info → Run anyway.
