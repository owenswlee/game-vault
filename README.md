# Game Vault

A small download site for my indie PC games, hosted on Cloudflare at https://game-vault.owenswlee.workers.dev.

- Game builds are attached to this repo's [Releases](https://github.com/owenswlee/game-vault/releases).
- Site files live in `public/`. Add or edit games in `public/games.js`.
- Deploy with `npx wrangler deploy` from this folder.
